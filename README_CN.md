# Banished 功能模组合集（DSH）

适用于 **Banished 1.0.7 build 170910**（Steam 版与非 Steam 版通用）。

六个独立模组，每个功能一个 .pkm，可以单独启用、单独删除，互不依赖。

## 模组列表

| 文件 | 名称 | 功能 |
|---|---|---|
| storage10x.pkm | 存储容量提升 | 堆料场 250→2500、谷仓 6000→60000、市场 10000→100000、贸易站 60000→600000、手推车 2500→25000 |
| infinitemine.pkm | 采石场与矿井无限产出 | 铁矿井与采石场最大产量 2000→2147483647，永不挖空 |
| pasture2x.pkm | 牧场容量提升 | 牛 20→10、羊 16→8、鸡 6→3，同面积养 2 倍牲畜 |
| limit8digit.pkm | 资源上限提升 | 资源上限输入框最大位数 6→8 位 |
| terratools.pkm | 地形工具 | 3 个 1x1 地形工具：抬高 1 格 / 降低 1 格 / 整平，零造价零工作量 |
| tombstonehalf.pkm | 墓碑留存时间减半 | 墓碑寿命 60 个月→30 个月，墓地不易堆满 |

## 安装

1. 完全关闭游戏
2. 把需要的 .pkm 复制到游戏安装目录下的 WinData 文件夹
3. 启动游戏，在主菜单的「模组」列表里勾选
4. 进入存档或开新局即可生效

## 卸载

删除 WinData 下对应的 .pkm 即可，各模组互不影响。

## 资源上限提升的额外步骤（可选）

游戏本体里资源上限的硬上限是 999999，该值写死在 exe 中。
想突破到 99999999，需要给 exe 打一个 4 字节补丁：

- 补丁工具在 optional/exe-patch/，双击 apply-patch.bat
- 会自动备份原文件为 Application-steam-x64.exe.orig_backup
- 想还原就运行 restore.bat
- 不打这个补丁也能正常用其它 5 个模组，只是上限停在 999999

## 兼容性

这些模组都采用「覆盖原版模板」的实现方式，因此与修改同类内容的模组冲突：

- 存储容量提升：与任何修改 谷仓 / 堆料场 / 市场 / 贸易站 / 手推车 的模组冲突
- 采石场与矿井无限产出：与任何修改 铁矿井 / 采石场 的模组冲突
- 牧场容量提升：与任何修改 牲畜 的模组冲突
- 资源上限提升：与任何修改 资源上限输入框 的模组冲突
- 墓碑留存时间减半：与任何修改 墓碑 的模组冲突
- 地形工具：占用原版 3 个隐藏工具栏槽位（debug / noise / capture），与同样修改这 3 个槽位的模组不兼容

大型合集类模组（MegaMod、Colonial Charter、RK Editor's Choice 等）基本与以上全部冲突。

## 已知限制

- 地形工具作用范围为 1 格（使用木桥桥面网格，这是游戏内唯一的 1x1 纯平地板）
- 地形工具在水面上使用时，深度相对水面而非河床，所以「降低」会把河床抬高
- 地形工具用完后需手动拆除（拆除后彻底消失，不留废墟）
- 存储 / 牧场 / 矿井 的改动只对新建建筑生效
- 墓碑寿命只影响之后新生成的墓碑
